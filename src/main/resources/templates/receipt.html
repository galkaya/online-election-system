Verify a confirmation code

Check that a ballot with your confirmation code was accepted. The check never shows who voted or which candidate was chosen.

✓ Accepted: A ballot with this code is stored and is included in the tally.
Not found: No stored ballot has this code. Check the code for typing mistakes.
Error: This is not a valid confirmation code. A code has 32 letters and digits, shown as eight groups of four.

Example format: ABCD-EFGH-JKMN-PQRS-TVWX-YZ01-2345-6789. Dashes and spaces are optional.
